## Purpose
Building out a character locomotion & combat prototypes using UE5 Mannequin & animations in a webgl enviroment for gaming prototyping.

## Setup
```
git clone --depth=1 https://github.com/sketchpunklabs/manne_3js.git
cd manne_3js
pnpm install -g browser-sync
pnpm run dev
```
